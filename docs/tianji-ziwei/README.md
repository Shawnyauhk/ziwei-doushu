# 倪海廈《天紀 · 紫微斗數》原話

這裡是倪海廈先生《天紀》課程中**紫微斗數部分**的原話，共 **1848 條**，按講次整理。每條都帶出處時間，點一下就跳回 B 站原影片的那一秒，可以自己核對。

內容取自姊妹倉庫 [nihai-tianji-corpus](https://github.com/Renhuai123/nihai-tianji-corpus)（天紀全量語料，提交 `462faa4`），這裡只是其中紫微部分的分講版本，**內容以語料庫為準**，會隨語料庫同步更新。

![倪海廈《天紀·紫微斗數》一圖看全](./overview.png)

## 收錄範圍

- **紫微斗數 14 講**：2上 至 15上，全部收錄，共 1808 條。
- **補充 1**：19上 第 2–4 段，即紫微在堪輿中的運用、鬥君、流月流日，共 29 條。
- **補充 2**：24下 裡講紫微的片段，共 11 條。

不收錄的：

- **1上 的斗數片段（命相同參）**：《天紀》完結版的語料裡沒有對應條目。
- **完整逐字稿**：只收倪師原話短引文和出處，不含能還原整堂課的逐字稿。
- **影片截圖和任何視聽內容**：所有出處都是指向 B 站原影片頁面的連結。

## 每一條長什麼樣

```
- [00:36:09](https://www.bilibili.com/video/BV1KJsLekEfA?p=9&t=2169) 「倪師原話」〔考據標註〕　冊目
```

- **時間**：這句話在該集影片裡的起始時間，點開就從這一秒開始播。
- **「」裡**：倪師原話。只刪口語贅詞和識別噪聲、補標點，不改字。
- **〔〕裡**：考據標註。
  - 字幕錯字經人工裁決改正的，寫作「已按裁決改正：錯字→正字」。
  - 倪師講解裡經排盤驗算確認的筆誤，寫作「勘誤：……」，原話照留。目前有 5上 一處，相關 4 條，說明見[語料庫勘誤頁](https://github.com/Renhuai123/nihai-tianji-corpus/blob/main/docs/%E5%8B%98%E8%AF%AF.md)。
- **冊目**：這句話在語料庫十一冊體系裡的位置，比如「主星 › 紫微 · 定性」。

`entries.jsonl` 是同一批內容的機器可讀版本，一行一條，欄位與語料庫相同，說明見[語料庫欄位說明](https://github.com/Renhuai123/nihai-tianji-corpus/blob/main/data/schema.md)。
